# Project Images

Tempatkan screenshot proyek Anda di folder ini dengan nama file:

- `project-1.png` — Sistem Informasi Perpustakaan
- `project-2.png` — E-Commerce Sederhana  
- `project-3.png` — Aplikasi Absensi Siswa
- `project-4.png` — Task Management API

**Spesifikasi gambar:**
- Rasio aspek: 16:10 (contoh: 1600×1000px, 1920×1200px)
- Format: PNG atau JPG
- Ukuran: < 500KB per gambar untuk performa optimal

Jika gambar belum tersedia, website akan menampilkan placeholder gradient otomatis.
